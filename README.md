# java-lotto-precourse

- 로또 번호
  - [x] 숫자 범위 = 1~45
  - [x] 중복되지 않은 숫자 6개
  - [x] 번호는 오름차순으로 저장

- 당첨 번호
  - [ ] 중복되지 않은 숫자 6개 + 보너스 번호 1개


- 당첨 금액
  - [ ] 1등(번호 6개 일치) - 2,000,000,000
  - [ ] 2등(5개 일치 + 보너스일치) - 30,000,000
  - [ ] 3등(5개일치) - 1,500,000
  - [ ] 4등(4개일치) - 50,000
  - [ ] 5등(3개일치) - 5,000

- 로또 구입 금액
  - [ ] 로또 한장 가격은 1,000원

  
## 입력

- [ ] "구입금액을 입력해 주세요."를 출력하고, 구입금액을 입력받는다.
  - [x] 숫자형식이어야함.
  - [ ] 양수여야함.
  - [x] 빈값 X
  - [ ] 1000보다 작으면 안됨

- [ ] "당첨 번호를 입력해 주세요."를 출력하고, 당첨번호 입력 받는다.
  - [ ] ","로 구분할 수 있는 6개의 번호

- [ ] "보너스 번호를 입력해 주세요."를 출력하고, 보너스 번호 입력받는다.
  - [ ] 당첨 번호와 중복되면 안 된다.
  - [ ] 1~45 범위여야한다.
  - [ ] 숫자 형식
