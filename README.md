# java-lotto-precourse

# 로또

----

- [ ] 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시키고, `[ERROR]`로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.
- [ ] Exception이 아닌 IllegalArgumentException, IllegalStateException 등과 같은 명확한 유형을 처리한다.

## 입력

### 1.구매 금액 입력

- [x] `구입금액을 입력해 주세요.`를 출력하고, 구입금액(long)을 받는다.
- [ ] 금액 검증을 한다.
    - [x] 양의 정수이어야한다.
    - [ ] 1000의 배수여야한다.
    - [ ] 1000 이상이어야 한다.
        - [ ] 예외
            - [x] 공백/빈 문자열이 들어올 경우
            - [x] 양의 정수 아닐 경우
            - [ ] 1000 보다 작을 경우(로또 1개도 못 삼)
            - [ ] 1000 배수 아닐 경우

### 2. 당첨 번호 입력

- [ ] `당첨 번호를 입력해 주세요.`를 출력하고, 당첨 번호(int[])를 입력받는다.
    - [ ] 번호는 쉼표(,)를 기준으로 구분한다.
    - [ ] 공백은 제거한다.
    - [ ] 번호 검증을 한다.
        - [ ] 번호는 모두 1~45 정수이다.
        - [ ] 번호는 중복되지 않는다.
        - [ ] 번호는 6개여야 한다.
            - 예외
                - [ ] 공백/빈 문자열이 들어올 경우
                - [ ] 번호가 1~45 아닐 경우
                - [ ] 번호가 중복될 경우
                - [ ] 당첨번호가 6개가 아닐 경우

### 3. 보너스 번호 입력

- [ ] `보너스 번호를 입력해 주세요.`를 출력하고, 보너스 번호(int)를 입력받는다.
- [ ] 보너스 번호 검증한다.
    - [ ] 번호는 1~45 정수이다.
    - [ ] 당첨번호와 겹치지 않는다.
        - 예외
            - [ ] 공백/빈문자열 들어올 경우
            - [ ] 당첨번호와 겹칠 경우
            - [ ] 번호가 1~45가 아닐 경우

## 로또 생성 및 발행

- [ ] 로또 한장당 가격은 `1000`원이다.
- [ ] 구매 개수를 구한다. `(구매금액 / 1000)`
- [ ] 구매 개수만큼 로또를 생성한다.
- [ ] 각 로또는 1~45 사이의 중복되지 않은 6개의 숫자를 가진다.
- [ ] 랜덤 번호는 `Randoms.pickUniqueNumbersInRange(1, 45, 6)`을 이용해 생성한다.
- [ ] 생성된 로또 번호는 오름차순으로 정렬한다.

## 당첨내역 계산

- [ ] 당첨번호와 사용자 로또가 몇개 맞는지 계산한다.
    - [ ] 5개가 같다면 보너스도 같은지 확인한다.
- [ ] 일치 개수와 보너스 여부를 기준으로 순위를 결정한다.
- `1등: 6개 일치`
- `2등: 5개 + 보너스 일치`
- `3등: 5개 일치`
- `4등: 4개 일치`
- `5등: 3개 일치`

- [ ] 순위별 당첨 개수를 집계한다.
- [ ] 총 당첨금액을 계산한다.

## 수익률 계산

- [ ]  `(총 당첨금액 / 구매금액 ) * 100` 을 통해 수익률을 계산한다.
- [ ] 소수점 둘째자리에서 반올림한다.

## 출력

- [ ] 구매한 로또 개수를 출력한다.(ex. `8개를 구매했습니다.`)
- [ ] 생성된 로또를 모두 출력한다.(ex. `[8, 21, 23, 41, 42, 43]` )
- [ ] 총 당첨 통계를 출력한다.
- [ ] 총 수익률을 출력한다. (ex. `총 수익률은 62.5%입니다.`)
